## 🚀 Featured Projects

### 🏛️ KMRL Document Intelligence & Sharing Platform
> **Smart India Hackathon 2025** · Role: Team Leader & Developer

A cloud-native platform built for **Kochi Metro Rail Limited (KMRL)** to eliminate document chaos — replacing scattered emails and WhatsApp files with a centralized AI-powered system.

**Key Features:**
- 🌐 Bilingual AI summarization (English & Malayalam) using **Google Gemini 1.5 Flash**
- 🔍 OCR extraction from scanned PDFs & images via **Tesseract**
- 📂 Full-text search across content, summaries, and metadata
- 📊 Analytics dashboard for document KPIs and pending tasks
- 🔒 Smart sharing across individuals, departments, or organization-wide

**Impact:** 90% reduction in document search time · Removes language barriers · Improves cross-department coordination

🛠️ `Flask` `PostgreSQL` `Dropbox API` `Google Gemini 1.5 Flash` `Tesseract OCR` `Docker` `Railway` `Tailwind CSS` `Jinja2`

---

### 🏥 MediPredict — Healthcare Predictive Analytics System
> Associated with **I SQUARE IT**

A full-stack ML application that predicts **diabetes risk** from patient health data with real-time analytics.

**Key Features:**
- 🤖 Logistic Regression model with **~76% accuracy & ~77% recall**
- ⚡ Flask-based REST API for real-time predictions
- 📊 Power BI dashboard visualizing glucose, BMI, and patient distribution trends
- 🗄️ MySQL database for storing patient inputs and prediction history

🛠️ `Python` `Scikit-learn` `Pandas` `NumPy` `Flask` `HTML/CSS/JS` `MySQL` `Power BI`

🔗 [GitHub Repository](https://github.com/HARSHP-16/MediPredict-.git) · 🌐 [Live Demo](https://medipredict.me)
